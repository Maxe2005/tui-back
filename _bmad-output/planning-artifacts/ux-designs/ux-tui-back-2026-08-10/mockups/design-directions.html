tui-back — 5 visual directions

Same fixed layout (top bar with EDT + zone tabs, two-pane content, footer keybinding hints) and same copy in every direction — only the palette, glyph/border language, density and accent texture change. Each direction is rendered twice: the Dashboard hero screen and the Update run-in-progress screen, so the personality reads consistently across both.

Accessibility note: every status keeps its glyph + color pairing (● up / ○ down / ✔ success / ✖ error / ⚠ warning) — color is never the sole differentiator. Where a direction could tempt a pure red/green pair, the palette instead shifts lightness and/or hue (olive-green vs brick-red, emerald vs ruby-magenta, phosphor-green vs amber, teal vs coral, mint vs pink-red) so the success/error contrast survives red-green color-blindness simulation, not just default vision.
Direction 1 — Warm / Organic

Hearth

Register: a cozy craft-desk lamp, not a server room.

Warm neutrals and softly rounded panels make the tool feel hand-built and welcoming rather than clinical — directly answering Max's "not bare-utilitarian" brief. A single confident terracotta accent marks selection/action so the eye never has to guess what's interactive, keeping it scannable even with the softer palette. Low-saturation warm tones are easy on the eyes across an all-day session.
